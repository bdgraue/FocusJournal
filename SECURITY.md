# Security Policy

## Reporting a Vulnerability

If you believe you have found a security vulnerability in Focus Journal,
please **do not open a public issue**.

Instead, please report it privately via GitHub Security Advisories:

1. Go to <https://github.com/WariKoda/FocusJournal/security/advisories/new>
2. Fill in a clear description, reproduction steps, and potential impact.

We will acknowledge your report within a reasonable timeframe and keep you
updated on progress toward a fix. Responsible disclosure is appreciated.

## Supported Versions

Only the latest released version receives security updates.
